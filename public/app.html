Getting Started
Wiserr · Senior Advisor Gig Builder
1
Get an Anthropic API Key
Go to console.anthropic.com, sign up or log in, then navigate to API Keys → Create Key. Copy the key — it starts with sk-ant-. New accounts receive free credits.
2
Enter the key in the sidebar
Paste your API key in the field at the bottom-left of this screen, under “Anthropic API Key”. It is saved only in your browser — never sent anywhere except directly to Anthropic.
3
Add a candidate
Click + New Candidate in the sidebar, then upload a résumé as a PDF or plain text file. The AI analyses the profile and generates 5 tailored Fiverr gigs in about 20–30 seconds.
4
Review and copy gig content
Click any gig card to expand it. Use the tabs to navigate between Description, Packages, Keywords, and FAQ. Every section has a Copy button — paste directly into Fiverr.
5
Export as a standalone page
Click Export Gig Page ↓ on any gig to download a fully designed HTML file. Export All ↓ downloads all 5 gigs at once.
Privacy: Your API key and all candidate data are stored only in your browser’s local storage. Nothing is sent to any server other than the Anthropic API during analysis.
